Кратко

Книга распространяется бесплатно в виде файла для скачивания. Автор и Neshta Production не собирают, не хранят и не передают персональные данные читателей при скачивании или чтении книги.

Скачивание книги

Для скачивания книги не требуется регистрация, создание учётной записи, оплата или предоставление контактных данных. В файл книги не встроены аналитика, реклама, средства отслеживания или механизмы передачи данных автору.

Хостинг

Сайт размещён с помощью GitHub Pages. GitHub может автоматически обрабатывать технические сведения, например IP-адрес, тип браузера и журналы запросов, в соответствии со своей политикой конфиденциальности. Автор книги не получает от GitHub персональные профили читателей.

Обращения по электронной почте

Если вы самостоятельно напишете автору, адрес электронной почты и содержание сообщения будут использованы только для ответа на обращение и необходимой переписки. Эти сведения не продаются и не используются для рекламных рассылок.

Сайт может содержать ссылки на сторонние сервисы. Их обработка данных регулируется собственными политиками этих сервисов.
